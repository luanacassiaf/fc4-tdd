## Instruções de execução
- Ter o [Node](https://nodejs.org/en/download) instalado
- Ter o [Node Package Manager](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm) instalado
- Instalar dependências do projeto
```
npm install
```
- Executar testes
```
npm test
```

> #### Nota
> No tópico **5. Testes de Cancelamento de Reserva**, foi solicitado um teste para garantir que o sistema retorne um erro ao tentar cancelar uma reserva inexistente. Contudo, o teste já existia e foi apenas renomeado para "deve retornar erro ao tentar cancelar uma reserva que não existe".
